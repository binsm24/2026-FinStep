# 결과 리포트 및 보관함 UI

신규 결과 화면과 보관함 상세에 같은 리포트 컴포넌트를 적용했다.

- 점수/100과 최종 대응 상태를 구분해 표시한다. 점수를 금융 역량 전체나 피해 확률로 표현하지 않는다.
- 기본점, 안전 행동 범주별 가점, 위험 범주별 감점과 사용자 원문 근거를 보여준다.
- 상한·하한 조정 이유와 위험 지속 39점 제한 이유를 표시한다.
- 판단 자료 부족은 0점 대신 미산정으로 표시한다.
- 이전 기준 결과는 새 100점 척도와 비교하지 않도록 이전 기준 표시와 안내를 제공한다. 기존 저장 데이터는 수정하지 않는다.
- 안전·위험 행동, 권장 대응, 단계별 대화 기록을 다시 확인할 수 있다.
- 로그인한 상태로 진단을 완료하면 서버가 결과를 자동 저장한다. 별도 저장 버튼은 제공하지 않는다.
- 비로그인 상태로 완료한 결과는 보관함에 저장하지 않는다. 이후 로그인하거나 완료 요청을 재전송해도 소급 저장할 수 없다.
- 자동 저장 안내에서 내 보관함으로 바로 이동할 수 있다.
- 보관함 목록과 상세에서 본인의 결과를 삭제할 수 있다. 삭제 시 해당 결과와 원본 시뮬레이션 기록을 함께 제거해 지연된 저장 요청으로 결과가 다시 생성되지 않게 한다.

보관함 목록 API에는 저장된 스냅샷의 점수와 채점 버전을 추가했다. 저장 당시 값만 읽으며 재채점하지 않는다. 목록은 최신순 12개 단위로 표시한다. 페이지 전체를 조회하기 전에는 전체 기록 수를 추정하지 않고 현재 페이지 개수만 표시한다.

목록 오류와 상세 오류를 구분하고 각각 재시도를 제공한다. 상세에서 돌아오면 클릭했던 기록으로 키보드 초점을 복원한다. 빈 보관함, 비로그인, 로딩, 미산정과 이전 기준 결과를 별도로 처리한다.

## 검증

- 프론트엔드 TypeScript 및 프로덕션 빌드, ESLint 검사
- 백엔드 자동 테스트 83개: 로그인, 자동 저장·재시도 중복 방지, 비로그인 완료 후 소급 저장 차단, 본인 결과 삭제·원본 제거, 목록 메타데이터, 기존 결과 호환 등 포함
- 합성 결과로 1440px PC와 390px 모바일 화면 확인
- 안전 종료 / 노출 후 중단 / 위험 지속 / 미산정 / 이전 기준의 5가지 리포트 상태 확인
- 대화 기록 펼치기, 목록 복귀 및 초점 복원, 페이지 이동, 목록·상세 오류 재시도, 빈 보관함·비로그인 안내 확인
- 시뮬레이션 완료 → 자동 저장 안내 → 보관함 이동 흐름, 비로그인 완료 후 로그인해도 저장되지 않는 흐름, 삭제 취소·오류·성공 흐름 확인

브라우저 검증은 로컬 빌드와 모의 API를 사용했다. 실제 Google 로그인이나 운영 DB에는 접근하지 않았다. 실제 서비스 반영과 운영 환경 점검은 배포 시 별도로 수행한다.

## 학습 화면 배치

홈으로 돌아가는 버튼과 ‘경제를 이해하는 첫걸음’ 큰 제목·설명을 제거하고 주제 카드 6개를 헤더 바로 아래에 배치했다. 학습 상세의 제목·여백도 줄여 개념 설명과 확인 퀴즈가 위쪽에서 시작하도록 했다. 로고의 홈 이동과 상세 화면의 학습 목록 복귀는 유지한다.

1920×1080과 1440×900에서 주제 카드 6개가 페이지 스크롤 없이 표시되는 것을 확인했다. 1920×1080에서 금리 퀴즈의 정답 해설과 다음 문제 버튼까지 화면 안에 표시되는 것을 확인했다. 작은 화면에서는 가독성을 위해 자연스러운 세로 스크롤을 허용한다.
