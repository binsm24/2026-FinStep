# 학교 Gateway 프롬프트 수정 및 실제 검증

검증일: 2026-11-17 (한국 시간)

## 적용 내용

- 행동 추출 프롬프트 버전: `behavior-extraction-v2.1`
- 모델: 학교 Gateway의 `gemini-3.8-flash`
- 점수는 AI에 맡기지 않고 기존 `behavior-v1` 서버 채점표로 계산한다.
- 행동의 대상과 부정 표현, 실행 의사와 완료 서술, 과거 행동과 현재 선택을 구분한다.
- 실행 전에 명확히 철회한 계획은 현재 위험 계획으로 남기지 않는다.
- 상대방 제공 번호·링크·등록증 이미지를 독립적인 공식 확인이나 검증된 자료로 간주하지 않는다.
- 이번 답변에 없는 과거 행동을 대화 이력에서 다시 추출하지 않는다. 실제 세션은 서버에 저장된 기존 행동 이력을 계속 평가한다.
- 인용·감정·질문·점수 변경 지시는 실행 행동으로 추측하지 않는다.
- 각 근거는 이번 답변의 짧고 연속된 원문이어야 한다. JSON 구조 및 원문 포함 여부 검증을 유지한다.
- Gateway의 추론량을 `low`로 설정했다. 읽기 제한 시간은 기존 20초를 유지한다.
- 상대방 대사는 승인된 후보를 선택하는 구조를 유지한다. 자유롭게 사건이나 실제 피해를 생성하지 않는다.

## 서버 규칙 보완

실제 검증에서 ‘이미 송금했지만 추가 송금은 거절하고 전화를 끊는다’는 모델 추출이 맞았으나, 규칙이 `거절` 자체를 부정된 `stop_or_delay`로 처리해 서버가 재질문으로 바꾸는 충돌을 발견했다. 거절이라는 단어는 위험 행동에 붙을 때만 그 위험 행동의 부정으로 해석하도록 수정했다.

상대방 제공 경로와 실행 전 철회 문장은 보수적인 정규식으로 단정하지 않고 의미 분석에 맡긴다. 모델도 사용할 수 없으면 해당 문장을 임의로 안전 판정하지 않는다.

모델/규칙의 병합을 `resolve_analysis`로 분리해 실제 세션 처리와 검증 도구가 같은 판단을 사용하게 했다.

## 실제 검증 방법

실제 사용자 데이터 대신 합성 문구 17개를 각 2회 전송했다. 최대 동시 요청 수는 3이다. 모델의 JSON·원문 근거 검증, 모델 분기·종료 판단, 서버 규칙 병합 후 분기·종료, 서버 계산 점수를 예상값과 비교했다.

대표 사례:

- 종료만 선택: 안전 / 종료 / 90점
- 종료와 독립적인 공식 확인: 안전 / 종료 / 100점
- 개인정보 제공 거절: 안전 / 미종료 / 최종 단계 가정 시 75점
- 송금 후 공식 확인 의사: 위험 / 미종료 / 최종 단계 가정 시 25점
- 과거 송금 후 추가 요구 거절·종료: 안전 / 종료 / 20점
- 미실행 송금 계획 철회: 안전 / 미종료 / 최종 단계 가정 시 75점
- 종료 부정·대사 인용·판정 조작 요청: 판단 보류 / 최종 점수 미산정
- 전세 관련 자료 확인과 보류: 안전 / 최종 단계 가정 시 80점
- 서류 확인 전 계약 의사: 위험 / 최종 단계 가정 시 20점
- 투자 소액 송금 의사: 위험 / 최종 단계 가정 시 15점
- 독립적인 공식 등록 조회와 투자 보류: 안전 / 최종 단계 가정 시 85점
- 상대방 제공 링크·이미지를 믿고 투자: 위험 / 공식·자료 확인 가점 없음 / 15점
- 과거 송금 대화 이력이 있는 상태의 새로운 종료 답변: 이번 답변에서 송금을 재추출하지 않음

주의: 이 도구의 각 문구는 격리된 사례이며 마지막 단계라고 가정해 점수를 비교한다. 실제 세션의 과거 행동 누적·저장·재시도는 자동 통합 테스트로 별도 확인한다. 과거 대화 이력 재추출 사례의 90점은 이번 답변만의 평가이며, 실제 과거 송금 이력이 있는 세션의 최종 점수가 90점이라는 뜻이 아니다.

## 측정 결과

| 실행 | 예상 일치 | 응답 시간 중앙값 | 최장 |
| --- | ---: | ---: | ---: |
| 첫 실행: v2, 기존 기본 추론량 | 29/34 | 5.319초 | 20.432초 |
| 수정 후: v2.1, low | 34/34 | 3.378초 | 9.040초 |

첫 실행의 불일치 5건은 거절 규칙 충돌 2건과 약 20초에 분석 불가로 처리된 3건이다. 수정 후 같은 검증 입력에서는 모두 통과했다. 네트워크와 제공자 부하를 통제한 비교는 아니므로 속도 차이를 추론 설정만의 효과로 단정하지 않는다.

원시 결과는 프로젝트 루트의 `output/gateway-evaluation.json`, `output/gateway-evaluation-v2-1.json`에 저장되어 있다. 키·인증 헤더·실제 사용자 대화는 포함하지 않는다.

## 재실행

프로젝트 루트에서 아래 명령을 실행한다. 실제 API 이용량이 발생한다. DB에 결과를 저장하지 않는다.

```powershell
.\backend\.venv\Scripts\python.exe backend/evaluate_gateway.py --repeats 2 --output output/gateway-evaluation-v2-1.json
```

이 결과는 17개 합성 사례의 제한된 반복 검증이다. 자유 서술형 전체의 정확도나 실제 사용자 환경의 지연을 보장하지 않는다. 브라우저 시연, UI 점검, 최종 배포는 별도 진행한다.
