# FinStep

> 금융 위험 대응을 연습하는 첫걸음

**FinStep**은 대학생과 사회초년생이 금융 위험 상황을 가상으로 체험하고, 자신의 판단과 대응을 돌아볼 수 있도록 만든 금융 교육 웹 서비스입니다.

[서비스 바로가기](https://project-finstep.vercel.app/)

## 개발 배경

보이스피싱, 전세사기, 투자사기처럼 일상에서 마주할 수 있는 금융 위험은 지식만으로 대응하기 어려울 수 있습니다. 특히 상대방이 빠른 결정을 요구하거나 권위를 내세우는 상황에서는 알고 있는 내용을 행동으로 옮기는 연습이 필요합니다.

FinStep은 금융 정보를 읽는 데서 한 걸음 더 나아가, 위험 상황에서 어떻게 행동할지 직접 선택하고 그 과정을 복습할 수 있도록 기획했습니다.

## 서비스 이용 흐름

**위험 상황 체험 → 행동 분석 → 결과 리포트 → 관련 지식 학습 → 보관함에서 복습**

사용자가 자신의 대응을 자유롭게 작성하면, 답변에서 확인된 행동에 따라 다음 상황이 달라집니다. 체험을 마친 뒤에는 대응 점수와 행동별 근거, 개선 방향을 확인할 수 있습니다.

## 주요 기능

### 금융 위험 시뮬레이션

세 가지 시나리오를 통해 익숙하지 않은 금융 결정을 연습합니다.

| 시나리오 | 체험하는 상황 |
| --- | --- |
| 보이스피싱 | 수사기관을 사칭하는 상대방의 정보 제공·송금 요구 |
| 전세사기 | 저렴한 매물과 빠른 계약을 권유하며 자료 확인을 미루는 상황 |
| 투자사기 | 고수익·원금 보장을 약속하며 즉시 참여를 요구하는 제안 |

각 시나리오는 최대 4단계로 진행되며, 통화 종료나 거래 철회가 명확하면 조기에 종료됩니다. 대응이 불명확한 경우에는 추가 질문을 통해 행동을 구체화합니다.

궁금한 점을 상대방에게 질문하면 같은 단계에서 상황에 맞는 답변을 들을 수 있습니다. 행동을 선택한 뒤에는 상대방의 반응과 이어지는 상황을 확인하며 다음 단계로 진행합니다.

### 행동 기반 결과 리포트

이번 시뮬레이션에서 확인된 대응을 0~100점으로 살펴보고, 안전 행동과 위험 행동이 어떻게 반영되었는지 확인합니다.

안전하게 중단한 경우, 확인 전까지 보류한 경우, 위험 행동 이후 중단한 경우 등을 구분해 결과를 안내합니다. 판단 자료가 부족하면 점수를 확정하지 않습니다.

점수는 이번 체험에서 관찰된 행동에 대한 평가이며, 전반적인 금융 역량이나 실제 피해 여부를 뜻하지 않습니다.

### 진단 결과 보관함

로그인한 상태에서 시뮬레이션을 완료하면 결과가 보관함에 자동 저장됩니다. 비로그인 상태로 완료한 결과는 보관함에 저장하지 않으며, 나중에 로그인해도 소급 저장하지 않습니다.

- 점수, 최종 대응 상태, 저장 일시 확인
- 행동별 가점·감점 근거와 권장 대응 복습
- 당시의 대화와 자신의 답변 다시 보기
- 이전 채점 기준의 결과와 점수 미산정 결과 구분
- 필요 없는 진단 결과와 당시 대화 기록 삭제

### 금융 지식 학습과 퀴즈

금리, 물가와 인플레이션, 신용점수, 등기부등본, 안전계좌를 내세운 사기, 원금 보장 투자에 관한 **6개 주제와 총 30개 퀴즈**를 제공합니다.

개념 설명과 생활 속 영향을 함께 살펴보고, 퀴즈의 정답과 해설을 통해 이해를 점검할 수 있습니다.

## 기술 구성

| 영역 | 사용 기술 |
| --- | --- |

| 백엔드 | Python, FastAPI |

AI가 사용자 답변의 행동을 추출하고, 서버가 정해진 기준으로 채점과 시나리오 분기를 결정합니다.

## 기대 효과와 발전 방향

FinStep은 위험 신호를 알아차리는 데서 그치지 않고, 요구를 거절하거나 독립적인 경로로 확인하는 대응을 연습하도록 돕고자 합니다.

향후에는 시나리오와 학습 콘텐츠를 확장하고, 사용자 피드백과 반복 이용 전후의 변화를 살펴보며 교육 도구로서의 활용 가능성을 검증할 계획입니다.
